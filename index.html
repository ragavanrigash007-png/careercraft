✔ Learn Git & GitHub (to save code online)

Month 2 – JavaScript & Frontend

✔ Learn JavaScript (add functions, buttons, actions)

✔ Build small projects — To-Do App, Calculator, etc.

Month 3 – Backend & Final Project

✔ Learn Node.js + Express.js and Database (MongoDB or MySQL)

✔ Connect frontend + backend (Full-Stack App) and Deploy project online (Netlify, Vercel, etc.)

Data Science Basics

Month 1 – Python & Data Foundations

✔ Introduction to Data Science concepts

✔ Python essentials: variables, data types, loops, functions and Working with libraries: NumPy, Pandas

✔ Data cleaning and manipulation and Importing and exporting data (CSV, Excel, JSON)

✔ Mini Project: Analyze a small dataset (e.g., COVID data)

Month 2 – Data Visualization & Statistics

✔ Descriptive statistics and probability basics and Data visualization with Matplotlib and Seaborn

✔ Exploratory Data Analysis (EDA) and Correlation, outliers, and data patterns

✔ Mini Project: Visualize trends in a real-world dataset (e.g., sales or weather data)

Month 3 – Machine Learning & Final Project

✔ Introduction to Machine Learning concepts and Supervised Learning: Linear & Logistic Regression

✔ Model evaluation: accuracy, precision, recall and Unsupervised Learning basics (Clustering)

✔ Final Project: Predict outcomes using a dataset (e.g., student scores, housing prices)

Graphic Design

Month 1 – Design Fundamentals & Adobe Photoshop

✔ Introduction to Graphic Design & color theory

✔ Principles of design (balance, contrast, alignment, hierarchy)

✔ Working with Adobe Photoshop

✔ Mini Project: Design a brand banner or poster

Month 2 – Illustrator & Vector Design

✔ Adobe Illustrator fundamentals and Working with shapes, pen tool, typography, and icons

✔ Creating logos, business cards, and branding materials and Understanding file formats for print and web

✔ Mini Project: Design a logo + business card for a sample brand

Month 3 – Advanced Design & Portfolio Development

✔ Introduction to Adobe InDesign (layouts & print design)

✔ Brand identity and visual storytelling and Poster, brochure, and flyer design

✔ Final Project: Complete a brand design package (logo, poster, brochure)

UI/UX Design

Month 1 – UX Foundations & Research

✔ Introduction to UI/UX Design

✔ UX vs. UI — Key Differences,Design Thinking Process,User Research & Personas

✔ User Journey Mapping and Competitive Analysis

✔ Mini Project: Create a user persona and journey map for a mobile app

Month 2 – UI Design & Prototyping

✔ Visual design principles (color, typography, spacing),UI elements — buttons, icons, forms, navigation and Tools: Figma / Adobe XD / Sketch

✔ Creating responsive layouts for web & mobile and Design systems and component libraries

✔ Mini Project: Design a responsive landing page in Figma

Month 3 – Usability Testing & Final Portfolio

✔ Usability testing & feedback techniques and Accessibility in UI design

✔ Micro-interactions & animations (Figma prototyping) and Collaboration with developers (handoff using Figma Inspect / Zeplin)

✔ Final Project: End-to-end app or website design (UX research → UI prototype)

Cybersecurity & Ethical Hacking

Month 1 - Cybersecurity & Networking Foundations

✔ Introduction to Cybersecurity

✔ Networking Basics and Linux for Ethical Hackers

✔ Security Fundamentals

✔ Mini Project: Design a secure home or small office network.

Month 2 - Ethical Hacking Tools & Techniques

✔ Ethical Hacking Introduction and Information Gathering & Scanning

✔ Vulnerability Assessment and System Hacking

✔ Mini Project: Perform a safe penetration test on a virtual machine (VM).

Month 3 - Web, Wireless Security & Defense

✔ Web Application Hacking and Wireless & Mobile Hacking

✔ Cyber Defense & Incident Response and Final Preparation

✔ Final Project: Perform a full penetration test on a simulated environment and submit a Penetration Testing Report with recommendations.

Mobile App Development

Month 1 - Basics of Mobile App Development

✔ Introduction to Mobile App Development

✔ Programming Fundamentals (Java / Kotlin / Dart)

✔ User Interface (UI) Desig and Practical Task

✔ Mini Project: Create a “Daily Notes” or “To-Do List” app with add/delete/edit features.

Month 2 - Intermediate Development & APIs

✔ Data Management and Connecting to the Internet

✔ State Management (for Flutter) and App Navigation

✔ Mini Project: Build a “News App” or “Movie Info App” that uses an external API to display real-time data.

✔ Firebase Integration and Notifications & Permissions
